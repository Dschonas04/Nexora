A self-hosted wiki with backlinks and a knowledge graph

Nested pages in a block editor, [[links]] in both directions and full text search. A Go service and PostgreSQL, Redis as an optional cache.

Features

Free unless marked Pro.

Nested pages
Unlimited depth, drag to reorder, autosave.
Backlinks
[[Page title]] links both ways, every page lists who points at it.
Knowledge graph
All pages and links, coloured by space.
Full text search
PostgreSQL search over titles and content.
Spaces and roles
Separate areas per team, read or write per account.
Versions and trash
Snapshot before every change, compare any two word by word, 30 days to undo a delete.
Templates
Meeting notes, how-to, project page, or your own; an empty page offers them.
Tasks
@name and 📅 date in a checklist make a task; one list gathers them from every page.
Diagrams
Mermaid code blocks drawn in place: flowcharts, sequences, Gantt.
Watch and contents
An inbox message when a watched page changes; a table of contents beside long pages.
API keys and webhooks
Bearer keys for scripts, signed webhooks for n8n and friends.
Installable app
A PWA on phone and desktop; pages you opened stay readable offline.
Attachments
Local disk or S3 (MinIO, Garage, AWS), with a viewer.
Comments
On every page, with mentions.
Import
Obsidian, Notion, Confluence or a folder of Markdown.
Markdown export
Every page, always free.
Two-factor sign-in
TOTP for every account.
Operations
Backups with pg_dump, Prometheus metrics, optional Redis cache.
Sharing Pro
Share pages with accounts or as a public read-only link.
Real-time editing Pro
Several people writing on one page at once.

Install

Images for amd64 and arm64 on ghcr.io and Docker Hub.

Docker, with the install script

Writes random passwords, pulls the images, starts and waits until Nexora answers. Run it again to update.

git clone https://github.com/Dschonas04/Nexora.git && cd Nexora
./docker/install.sh          # or: ./docker/install.sh single

Single container

Database included. For trying it out and small teams.

docker run -d -p 3443:443 -p 3000:80 -v nexora_data:/data ghcr.io/dschonas04/nexora-single

Kubernetes

PostgreSQL, backend, frontend and an ingress, applied with kustomize.

./kubernetes/install.sh wiki.example.org

Then open https://localhost:3443. The first account becomes the administrator. More in the README.

Limits

What Nexora does not do.

  • No databases or boards. It is a wiki, not Notion.
  • No plugins and no AI assistant.
  • Small community. Mostly developed by one person.
